Entenda o projeto

Projeto de estruturação e análise curricular para os cursos de Ciência da Computação (CCO) e Sistemas de Informação (SIN). Esta ferramenta utiliza algoritmos de grafos para processar seu histórico escolar, identificar matérias pendentes, verificar equivalências automáticas e sugerir a melhor combinação de disciplinas para os próximos períodos.
